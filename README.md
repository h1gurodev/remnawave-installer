# Remnawave Installer

Интерактивный установщик [Remnawave](https://docs.rw) «под ключ»: **панель, страница подписок, VPN-ноды (VLESS Reality), Caddy с SSL**. Одна команда, дальше скрипт сам спрашивает, что и куда ставить. Без аргументов и правки конфигов руками.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/h1gurodev/remnawave-installer/main/install.sh)
```

Запускать от `root` на чистом сервере с Debian или Ubuntu.

---

## Что умеет

- **Красивый консольный интерфейс**: градиентный баннер, меню на стрелках `↑ ↓` + `Enter`, переключатели «Да / Нет», спиннеры с прогрессом установки, итоговые карточки.
- **Всё на один сервер**: панель, страница подписок и нода на одной машине.
- **Панель + страница подписок**: без ноды, ноды подключаются потом.
- **Нода к существующей панели**, два способа:
  - **автоматически**: по API-токену скрипт сам создаёт в панели профиль Xray (VLESS Reality), ноду, хост и добавляет её в сквад;
  - **вручную**: вставляешь `SECRET_KEY` из панели.
- **Страница подписок на отдельном сервере.**
- **Маскировка Reality**:
  - свой **сайт-заглушка** (self-steal), домен с настоящим SSL от Let's Encrypt;
  - или **чужой сайт** (samsung, nvidia, microsoft, dl.google.com, свой вариант). Перед выбором скрипт проверяет, что сайт отдаёт TLS 1.3 и h2.
  - Fingerprint в хостах — `firefox`.
- **Секретная ссылка для панели**: без `?auth=…` домен панели молча рвёт соединение, и сканеры панель не находят. API по токену при этом работает (страница подписок, ноды, боты).
- **Сам делает всё рутинное**:
  - ставит Docker;
  - генерирует секреты и пароль админа (24+ символов);
  - регистрирует суперадмина;
  - выпускает API-токены;
  - выпускает SSL через Caddy;
  - открывает порты в `ufw`, если он включён;
  - проверяет DNS доменов и занятость портов;
  - создаёт тестового пользователя и отдаёт готовую ссылку-подписку.
- **Если шаг упал**, скрипт показывает хвост лога и предлагает: *повторить*, *пропустить* или *выйти*. Если недоступен Docker Hub, можно включить зеркало одной кнопкой.
- **Меню управления** — команда `remna`: статус, логи, обновление, перезапуск, бэкап, данные доступа, удаление.

## Требования

| | |
|---|---|
| ОС | Debian 11+ / Ubuntu 20.04+ (x86_64 или arm64) |
| Права | root |
| Панель | от 1 ГБ RAM, лучше 2 ГБ |
| Нода | от 512 МБ RAM |
| Домены | A-записи на IP сервера. В Cloudflare — только «DNS only» (серое облако) |
| Порты | 80 и 443 свободны. Для ноды: порт VPN и порт API ноды (по умолчанию 2222) |

Сколько доменов нужно в каждом режиме:

| Режим | Домены |
|---|---|
| Всё на один сервер | панель + подписки (+ заглушка, если выбран self-steal) |
| Панель + подписки | панель + подписки |
| Нода | не нужен (или один для заглушки) |

## Что и куда ставится

| Путь | Что там |
|---|---|
| `/opt/remnawave` | панель: `docker-compose.yml` (официальный), `.env` |
| `/opt/remnawave/subscription` | страница подписок |
| `/opt/remnawave/caddy` | Caddy: `Caddyfile`, сайт-заглушка |
| `/opt/remnanode` | нода (`remnanode`), для self-steal — свой Caddy на `127.0.0.1:9443` |
| `/root/remnawave-credentials.txt` | ссылки, логин и пароль, токены (`chmod 600`) |
| `/root/remnawave-backups` | бэкапы из меню `remna` |
| `/var/log/remnawave-installer.log` | подробный лог всех шагов |

Структура совпадает с [официальной документацией](https://docs.rw/docs/install/remnawave-panel), так что любые гайды Remnawave подходят и к этой установке.

## Несколько серверов

1. На сервере панели выбери **«Панель + подписки»**. В конце скрипт выдаст `NODES_API_TOKEN`.
2. На каждом сервере ноды выбери **«Нода» → «Автоматически»**. Введи адрес панели и этот токен. Нода сама появится в панели, получит профиль Reality и хост и встанет в сквад.

## Управление

```bash
remna            # интерактивное меню
remna backup     # бэкап базы и конфигов (удобно для cron)
remna update     # обновить все компоненты
remna status     # состояние контейнеров
```

Бэкап на каждую ночь:

```bash
echo '0 4 * * * root /usr/local/bin/remna backup' > /etc/cron.d/remna-backup
```

Восстановить базу из бэкапа:

```bash
mkdir /tmp/rw && tar -xzf /root/remnawave-backups/remnawave-XXXX.tar.gz -C /tmp/rw
zcat /tmp/rw/db.sql.gz | docker exec -i remnawave-db psql -U postgres -d postgres
```

## Частые вопросы

**SSL не выпускается.** Проверь, что A-запись указывает на сервер, домен не проксируется через Cloudflare и порты 80/443 открыты в панели хостера. Логи: `remna` → «Логи» → `remnawave-caddy`.

**Не качаются образы (Docker Hub недоступен).** В меню ошибки выбери «Через зеркало». Скрипт пропишет `mirror.gcr.io` и `dockerhub.timeweb.cloud` в `/etc/docker/daemon.json` и повторит загрузку.

**Потерял секретную ссылку на панель.** Она лежит в `/root/remnawave-credentials.txt`. Ключ также виден в `/opt/remnawave/caddy/Caddyfile`.

**Нода не подключается.** Порт API ноды (по умолчанию 2222) должен быть доступен с IP панели. Проверь фаервол хостера и логи `remnanode`.
